 # Summary for My Project

For this project i had decided to make a 2D shooter where the main goal is to defeat as much enemies as you can without dying and getting the best possible score.

 # Features
- Different UI featuring an interactive main menu, responsive Health bar
- working shooting system
- invincibility that lasts a few seconds
- Enemy movement
- enemy health
- enemy awareness
- enemy attack
- enemy spawners

  # Software Used
  - unity
  -  c sharp
  -  asset store
